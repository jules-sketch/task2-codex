# Buddie Roman Numeral Calculator

A simple Roman numeral calculator with history support.

## Running locally

You can try the calculator directly from the repository without any dependencies:

1. Open `index.html` in your browser (double-click or drag the file into a tab), or
2. Serve the folder to avoid file URL restrictions:
   ```bash
   python3 -m http.server 8000
   ```
   Then visit http://localhost:8000 in your browser.

## Features
- Enter Roman numerals and perform addition, subtraction, multiplication, and division.
- View and toggle a calculation history list and clear previous entries as needed.
